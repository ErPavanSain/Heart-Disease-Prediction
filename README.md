# Heart Disease Prediction – Model Evaluation

## Project Overview
This project focuses on analyzing heart disease data and evaluating a classification model to predict the possibility of heart disease. The main objective is to assess the model's performance using important classification evaluation metrics.

## Objectives
- Analyze and preprocess the Heart Disease dataset.
- Prepare data for classification.
- Train and evaluate a classification algorithm.
- Measure model performance using evaluation metrics.

## Technologies & Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Evaluation Metrics
The model performance was evaluated using the following metrics:

1. **Accuracy Score:** Measures the overall percentage of correct predictions.
2. **Precision Score:** Measures how many positive predictions were actually correct.
3. **Recall Score:** Measures how many actual positive cases were correctly identified.

## Key Learnings
- Understanding classification problems.
- Data preprocessing and analysis.
- Implementing model evaluation techniques.
- Understanding the importance of Precision, Recall, and Accuracy.

## Conclusion
This project demonstrates the evaluation of a classification model on heart disease data. It provides practical experience in understanding model performance through different evaluation metrics.
